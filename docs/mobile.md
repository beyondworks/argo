# 휴대폰에서 열기 — PC가 켜져 있는 동안 폰으로 아르고 쓰기

아르고의 실행(러너·기억·산출물)은 전부 PC에서 돕니다. 폰은 그 PC의 **화면**입니다. 그래서 폰에서 쓰려면 PC가 켜져 있고
아르고가 떠 있어야 하며, 폰이 PC에 네트워크로 닿을 수 있어야 합니다. 폰에는 러너 자격이나 회사 데이터가 저장되지 않습니다.

## 1. 켜기 (PC)

1. 아르고 → 설정 → 기기 → **휴대폰에서 열기** 카드에서 **켜짐**을 누릅니다.
2. 처음 켤 때 macOS·Windows 방화벽이 "들어오는 연결을 허용할까요?"라고 물으면 **허용**합니다.
3. 카드에 **주소**, **QR**, **6자리 코드**가 뜹니다. 코드는 5분 뒤 만료되고, 한 번 쓰면 사라집니다(새 코드 버튼으로 재발급).

켜기 전에는 폰이 닿을 수 있는 포트가 아예 열리지 않습니다. 켠 뒤에도 코드로 페어링한 폰의 요청만 통과하고, 그 외 요청(토큰 없음·해제된 토큰·이 컴퓨터인 척 꾸민 Host 헤더)은 거절됩니다. 예외는 페어링 페이지와 `/api/ping`(버전 확인, 비밀 없음)뿐입니다.

## 2. 연결하기 (폰)

- **같은 와이파이**: 폰 카메라로 QR을 비추면 `http://<PC 주소>:3031/m/pair?c=<코드>`가 열리고 자동으로 연결됩니다.
- QR을 못 쓰면 폰 브라우저(또는 아르고 앱의 연결 화면)에 주소를 직접 입력하고 코드를 칩니다.
- 연결된 폰은 설정 카드의 **연결된 휴대폰** 목록에 뜹니다. **연결 해제**를 누르면 그 폰은 즉시 접근이 끊깁니다.

## 3. 밖에서도 쓰기 (Tailscale)

집·사무실 밖에서 쓰려면 **Tailscale**(무료 개인 플랜)로 PC와 폰을 같은 사설망에 넣습니다.

1. PC와 폰에 Tailscale을 설치하고 같은 계정으로 로그인합니다.
2. 설정 카드의 **주소** 드롭다운에서 `100.x.x.x — Tailscale` 주소를 고릅니다. QR이 그 주소로 바뀝니다.
3. 폰(Tailscale 켜진 상태)에서 QR을 비춥니다. 이후엔 LTE에서도 그 주소로 열립니다.

Tailscale 구간은 암호화됩니다. 같은 와이파이 구간은 평문 HTTP입니다(카페 같은 공용 와이파이에서는 켜지 마세요).

## 4. 아르고 앱(iOS·Android)

폰 브라우저 대신 아르고 앱을 쓰면 홈 화면 아이콘으로 바로 열립니다. 앱은 `mobile/`(Capacitor)에 있고, 화면은 **연결 화면 하나**뿐입니다.
연결되면 WebView가 PC의 아르고(위 주소)를 그대로 보여 주므로, 이후 화면·기능은 폰 브라우저와 같습니다.

- 첫 실행: **QR 스캔**(카메라 권한) 또는 주소·코드 직접 입력. `argo://pair?u=<주소>&c=<코드>` 링크로도 열립니다.
- 다음 실행부터: 마지막 PC에 3초 안에 응답이 오면 바로 홈으로, 없으면 연결 화면으로 돌아옵니다.
- 앱 자체에는 회사 데이터·러너 자격이 저장되지 않습니다(페어링 쿠키만 WebView에 남습니다).
- 지원 버전: iOS 15 이상, Android 8.0(API 26) 이상. QR·딥링크(`argo://pair`)로 들어온 주소는 집·사무실 사설망과 Tailscale 범위만 자동 연결하고, 그 밖의 주소는 직접 입력으로만 연결됩니다.

개발자 빌드:

```bash
cd mobile && npm install && npx cap sync
```

```bash
cd mobile && npx cap run ios --target "<시뮬레이터 UDID>"
```

```bash
cd mobile && npx cap run android
```

Android 빌드는 JDK 21이 필요합니다(QR 스캐너 플러그인이 21 툴체인을 요구하고, Gradle 8.11은 JDK 25를 지원하지 않음 — `JAVA_HOME=/opt/homebrew/opt/openjdk@21` 같은 식으로 지정). iOS는 Swift Package Manager로 구성돼 CocoaPods가 필요 없습니다(`capacitor.config.json`의 `ios.packageManager`). 평문 HTTP 접속을 위해 iOS `NSAllowsArbitraryLoadsInWebContent`+`NSAllowsLocalNetworking`, Android `usesCleartextTraffic`가 켜져 있습니다 — 사용자 자신의 PC에 붙기 위한 설정이며, 스토어 심사 시 이 문서의 1~3절을 사유로 제시합니다.

### 스토어 발행 체크리스트(유건 소관)

- 번들 ID `com.beyondworks.argo.mobile` 등록, Apple Developer·Google Play 개발자 계정 서명 설정
- 앱 아이콘·스플래시를 `Argo_gold.svg` 정본으로 교체(`@capacitor/assets`)
- iOS 심사 사유: ATS 예외(자기 PC 사설망 접속), 로컬 네트워크·카메라 권한 문구(Info.plist에 한국어로 기재됨)
- TestFlight·Play 내부 테스트 → 실기기 와이파이·Tailscale 각 1회 페어링 실측

## 5. 하지 말아야 할 것

- **공유기 포트포워딩으로 3031을 인터넷에 공개하지 마세요.** 코드 없이는 통과하지 못하지만, 그래도 밖에서는 Tailscale이 답입니다.
- 셀프호스트 문서의 "포트를 공개로 열지 말 것" 원칙은 그대로입니다. 이 기능은 서버 바인딩(127.0.0.1)을 바꾸지 않고, 켜져 있는 동안만 같은 프로세스 안에 별도 리스너를 둡니다.

## 6. 한계

- 끄기 버튼은 지금 켜져 있는 아르고 프로세스의 리스너만 닫습니다. 상주 서비스와 데스크톱 앱이 같은 작업 폴더로 동시에 떠 있으면 다른 쪽 프로세스의 포트는 그 프로세스를 재시작해야 닫힙니다(요청 자체는 토큰 없인 거절됩니다).

- PC가 잠들면(노트북 덮개 닫힘) 폰도 끊깁니다. 상시 사용은 절전 해제 또는 셀프호스트 VPS를 권합니다.
- 와이파이 주소(192.168.x.x)가 바뀌면 폰이 못 찾습니다. 설정 카드에서 새 QR로 다시 페어링하세요. Tailscale 주소는 바뀌지 않습니다.
- 알림은 텔레그램·슬랙 브리핑을 그대로 씁니다. 폰 화면 안에서는 결재 대기 수와 크루 상태 점으로 대신합니다.
- 러너 연결·작업 폴더 지정·기억 그래프·경쟁 시안 비교는 PC 화면에서 하세요. 폰은 지시·열람·결재·진행 확인에 맞춰져 있습니다.

## 7. 문제 해결

| 증상 | 확인 |
|---|---|
| QR을 열었는데 응답이 없다 | PC와 폰이 같은 와이파이인지, 방화벽 허용을 눌렀는지, 카드가 **켜짐**인지 |
| "코드가 만료됐습니다" | 카드에서 **새 코드** → 다시 스캔 |
| 갑자기 401·"다시 연결" 화면 | PC에서 연결 해제됐거나 토글이 꺼진 상태. 다시 페어링 |
| 포트가 이미 사용 중 | 다른 프로그램이 3031을 쓰는 중. 그 프로그램을 끄거나 아르고를 재시작 |
