# 그룹챗 구상 — 사람 여럿 + 크루가 한 방에서 대화 (2026-07-25 초안)

> North Star 확장: "프롬프트 한 줄로 만든 AI 직원 회사"에 **사람 동료가 합류**한다.
> 사장 혼자 크루를 부리는 회사에서 → 팀원들이 같은 크루와 한 방에서 일하는 회사로.

## 이미 있는 기반 (재사용 대상)

- **텔레그램 그룹**: 봇을 그룹에 초대해 @멘션·답장으로 대화 가능. 단 현재는 **페어링된 사장 발화만** 크루가 처리(TOFU 방지 설계).
- **회의실(room)**: 크루 간 다자 토론 스레드 + SSE 스트림. 사람은 사장 1명만 참여.
- **권한 모델**: `ownerId`(회사 소유) + 결재(approvals) + 능력 게이트 — 전부 "사장 1인" 전제.
- **리더 기기**: 루틴·기억 정리·게이트웨이 폴은 항상 한 기기(클라우드 리스) — 다자 접속에도 실행 지점은 하나라 경합 없음. (예외: 크루 우편 배달은 기기 로컬 큐라 발신 기기가 직접 배달 — 2026-07-28 리더 게이트 분리.)

## 단계 제안 (MVS 순 — 각 단계가 그 자체로 출하 가능)

### 1단계 — 텔레그램 그룹 개방 (가장 작고, 반쯤 이미 있음)

사람 추가 = 텔레그램 그룹에 초대. 앱 변경은 게이트웨이만.

- **멤버 승인(화이트리스트)**: 그룹에서 낯선 사람이 처음 발화하면 크루가 응답하지 않고, 사장에게 "OOO을 멤버로 승인할까요?" 결재 카드(기존 approvals 재사용). 승인된 텔레그램 user id만 크루가 응답.
- **발화자 태깅**: 멤버 발화를 턴 입력에 `〔민수〕 내용` 형태로 전달 — 크루가 **누구의 말인지** 알고 답하며, vault 기억에도 발화자가 남는다.
- **권한 경계 유지**: 결재 버튼·능력 켜기·설정 변경은 사장만(기존 ownerId·bySender 검사 그대로). 멤버는 지시·질문만.
- **폭주 가드**: 그룹에서는 @멘션 또는 봇 답장에만 반응(현행 유지) + 멤버별 분당 rate limit.
- 규모 감: 게이트웨이 수정 + 멤버 목록 파일(connections.json 확장) + 승인 카드 1종.

### 2단계 — 인앱 회의실 멀티유저

회의실을 "사람들 + 크루들"의 방으로 확장. 사장 기기(리더)가 호스트.

- **멤버 계정**: Supabase 계정으로 회사에 멤버 초대(이메일 링크). `company.members[]` — 열람·발화 가능, 결재·설정·구동 불가.
- **접속 경로가 관건**: 같은 네트워크/사설망(tailscale류)이면 사장 상주(:3001)에 바로 접속. 원격 일반 사용자는 3단계의 클라우드 릴레이 필요 — 2단계는 "같은 사무실/VPN 팀" 스코프로 정직하게 한정.
- **UI**: room 스트림(SSE)에 사람 발화를 합류 — 발화 규칙은 1단계와 동일(크루는 사람 발화·@멘션에만 반응, 크루↔크루 연쇄는 기존 위임 경로만).

### 3단계 — 클라우드 채널 (cloud-hybrid 트랙 합류)

- 방 메시지를 Supabase Realtime으로 브로드캐스트 — 멤버는 어디서든 웹 접속, **방 턴 실행은 여전히 리더 기기**(로컬 우선 불변. 단 크루 우편 배달만은 발신 기기 몫 — scheduler.mjs 2026-07-28).
- E1b 봉투 암호화 스위치와 결합해 메시지 중계도 암호문으로.
- 멤버 초대는 Pro 축(멀티디바이스와 같은 과금 축)에 자연 편입.

## 발화·권한 규칙 (전 단계 공통)

## 열린 질문 (구현 전 결정 필요)

1. **기억 귀속**: 멤버와의 대화도 회사 vault에 전부 남는데, 멤버가 나가면? (제안: 회사 기억은 회사 것 — 퇴사자와 동일 취급, 문서화만)
2. **멤버 프로필**: 크루가 멤버별 취향·맥락을 기억하게 할지(사장-프로필.md의 멤버 버전) — 1단계에선 발화자 태깅만, 프로필은 후속.
3. **결재 노출**: 그룹에서 결재 카드를 모두에게 보일지, 사장 DM으로만 보낼지. (제안: 그룹에 요약 + 버튼은 사장 검사 유지 — 투명성과 권한 분리 양립)

"사람 여럿 + 크루 그룹챗"의 사용자 결과를 가장 빨리 실증한다. 2·3단계는 1단계 실사용 반응을 보고 확정.
