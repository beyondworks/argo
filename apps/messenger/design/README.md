## 분리 평가 (다른 컨텍스트)

- 1차: **8.1 / 10**(독창성 7.5 · 크래프트 8.0 · 기능성 7.5 · anti-slop 9.0) — 재작업. 지적 15건은 위 표.
- 2차: **8.6 / 10**(독창성 7.5 · 크래프트 8.7 · 기능성 8.8 · anti-slop 9.2) — **통과(8.5 기준)**. 1차 지적 1~15 폐합을 평가자가 직접 재측정(대비·우측 가장자리 픽셀·라벨 자간). 남은 결함 6건(전부 값 수준)은 평가 직후 반영:
  1. 다크 대기 카드 옐로 워시가 fg-3 대비 3.84·카키로 탁함 → `--mark-wash` 토큰(라이트 7% 워시 / 다크 `--card`).
  2. "처리 중" 카드의 상태 라벨 모순(결재 대기 + 처리 중, disabled 버튼 노출) → "승인됨 · 실행 중" + 확정 필 + 실행 중 줄, 버튼 제거.
  3. 컴포저 우측이 스레드보다 스크롤바 폭(11px)만큼 넓음 → 스레드·독 모두 `scrollbar-gutter: stable both-edges`.
  4. 크루 상태 "대기 중"·내 글 메타 "전송 중…"이 모노 폴백 → Pretendard 11px, 시각 숫자만 `.mono`.
  5. 전송 중 버블 4.36·"전송 실패" 4.42(라이트, 4.5 턱밑) → sending .7, 라이트 `--danger` 어둡게(4.6+).
  6. 라이트 스켈레톤 바가 캔버스와 1.08 → `--secondary`.
  평가자 미확인 항목: 390 폭 넘침 수치(교차 출처 iframe — 구현자 측정값 0으로만 기록), 실제 마우스 호버(focus-within 등가로 확인), 다크 390.
