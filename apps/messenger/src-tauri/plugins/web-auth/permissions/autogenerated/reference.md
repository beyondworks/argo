## Default Permission

iOS 로그인 창을 열고 콜백 URL을 돌려받는 start 명령

#### This default permission set includes the following:

- `allow-start`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`web-auth:allow-start`

</td>
<td>

</td>
</tr>

<tr>

</td>

</td>
</tr>
